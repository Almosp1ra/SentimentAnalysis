# 数据库应用系统：社交媒体活动的情感倾向监测与时空分布分析

## 项目简介
本项目为数据库系统原理课程设计期末作业，围绕社交媒体数据的情感分析与时空分布存储，设计并实现了一个基于关系型数据库的情感监测与查询系统。
系统支持社交媒体数据导入、情感分析、关键词与话题管理、多维条件查询以及基础可视化与数据导出，可用于舆情分析、热点监测与情感趋势研究。

## 数据来源
系统测试数据来源于 Kaggle 数据集 **COVID19 Tweets**，该数据集基于 Twitter API 收集，包含约 90,000 名用户在 2020.07–2020.08 期间发布的约 178,000 条推文，每条数据包含用户、时间、文本内容、地理位置与话题标签等信息。

## 技术栈
- 后端：Python 3.13.2 + Flask 3.1.2
- 数据库：MySQL 9.4.0（Docker 容器化部署）
- 前端：HTML + Tailwind CSS + JavaScript
- 情感分析模型：
  - TextBlob（快速情感分析）
  - BERT（高精度情感分析）
- 数据库设计：满足 3NF，合理使用主键与辅助索引

## 系统功能
- 用户与角色管理（admin / analyst / ingest）
- 社交媒体数据导入与管理
- 推文情感分析及结果管理（支持多模型）
- 关键词与话题提取与关联
- 多维条件查询（时间、话题、关键词、模型等）
- 情感分布与趋势可视化
- 分析结果数据导出

## 数据库说明
数据库采用 MySQL，通过 Docker 方式部署。源码中包含数据库表结构与索引设计相关 SQL，运行环境与实际数据未随源码一并提交。
